CBOM Check

Semantic checks for CycloneDX 1.6 and 1.7 Cryptography Bills of Materials.

Passing the schema does not mean a CBOM is correct. This checks what the CBOM says: NIST levels against FIPS 203/204/205, asset modelling, incomplete parameter-set names, missing classical algorithms, what changed since a previous version, and agreement with an ACVP test report. Optional profiles add CERT-In minimum elements, weak algorithms and CNSA 2.0.

Checks

  • CBOM_SCHEMA_INVALID: baseline CycloneDX 1.6 / 1.7 schema validation
  • CBOM_ASSET_MISSING_CRYPTO_PROPERTIES
  • CBOM_ASSETTYPE_IMPLAUSIBLE: heuristic, warning only; the modelling decision is yours
  • CBOM_NIST_LEVEL_ON_NON_ALGORITHM, CBOM_NIST_LEVEL_MISMATCH
  • CBOM_PARAMETER_SET_NAME_INCOMPLETE, CBOM_NO_CLASSICAL_ALGORITHMS
  • CBOM_SERIALNUMBER_NOT_REFRESHED, CBOM_TIMESTAMP_NOT_REFRESHED
  • ACVP_ALGORITHM_NOT_IN_CBOM, CBOM_ALGORITHM_NOT_TESTED, ALGORITHM_NAME_MISMATCH
  • CBOM_CERTIN_ELEMENT_MISSING: optional; CERT-In CBOM minimum elements (Technical Guidelines v2.0)
  • CBOM_WEAK_ALGORITHM: optional; MD5, Triple DES, RSA below 2048 bits (errors), SHA-1 and DSA (warnings), per NIST SP 800-131A Rev. 2 and FIPS 186-5
  • CBOM_CNSA2_NOT_ALLOWED, CBOM_CNSA2_TRANSITIONAL: optional; NSA CNSA 2.0 (AES-256, SHA-384/512, ML-KEM-1024, ML-DSA-87, LMS/XMSS; classical public-key algorithms only during the transition)

Limits

The assetType check is a heuristic; every other check is deterministic. It does not check inventory completeness, certificate contents, or whether an ACVP report is genuine; key sizes are only read from algorithm names and parameter-set identifiers. Self-run test vectors are not CAVP validation.

Reproducible results

The downloaded result names the SHA-256 of every input file and the checker version, so anyone can run the same files and get the same result. It is not a timestamp: for proof of when a CBOM passed, ActaSeal seals the result.

Privacy

The checker is Python running in your browser (Pyodide). Your files are read locally and never sent anywhere. The same code runs as a CLI: python cbom_check.py cbom.json --acvp report.json --baseline old.json --strict
